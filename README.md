> Storyboard & prompt templates for AI short dramas · 中文优先 · 拿来即用

一套可以**直接套用**的中文模板与提示词集合，专治 AI 短剧 / 漫剧生产里最常见的四个问题：

| 常见坑 | 本仓库给什么 |
|---|---|
| **节奏排不出来** —— 一集 60~90 秒，钩子放哪、反转放哪全靠感觉 | [`docs/01-短剧节奏与分镜结构.md`](docs/01-短剧节奏与分镜结构.md)：六段式节奏表 + 每段镜头数与单镜时长配比 |
| **镜头说不清** —— 想写"电影感"，最后只会写"高清、精美、4K" | [`prompts/01-镜头语言对照表.md`](prompts/01-镜头语言对照表.md)：景别 / 机位 / 运镜 / 焦段 / 构图的中英提示词对照 |
| **角色会漂移** —— 第 1 集和第 3 集男主不是同一张脸 | [`prompts/03-角色一致性.md`](prompts/03-角色一致性.md)：八槽位描述块 + LOOK 编号 + 三视图参考图法 |
| **风格不稳定** —— 同一集里一半国漫一半写实 | [`prompts/04-画风与质感.md`](prompts/04-画风与质感.md)：把"风格"拆成可复用的固定前缀 |

## 怎么用（三条最短路径）

**路径 A｜从零做一集**
1. 读 [`docs/01-短剧节奏与分镜结构.md`](docs/01-短剧节奏与分镜结构.md)，选一个题材模板（`storyboard/`），套节奏表。
2. 用 [`workflow/01-小说转分镜.md`](workflow/01-小说转分镜.md) 的提示词，让大模型把你的剧情梗概转成分镜表 JSON。
3. 逐镜用 [`prompts/01`](prompts/01-镜头语言对照表.md) + [`prompts/02`](prompts/02-光线与氛围.md) 补画面描述，出图。
4. 出图前先按 [`prompts/03-角色一致性.md`](prompts/03-角色一致性.md) 锁定角色描述块，再批量生成。

**路径 B｜已经会出图，但成片"不对劲"**
直接跳到 [`prompts/03-角色一致性.md`](prompts/03-角色一致性.md) 和 [`workflow/02-图生视频参数.md`](workflow/02-图生视频参数.md)。九成的"廉价感"来自角色漂移 + 运镜乱给。

**路径 C｜只想找一段能抄的提示词**
`prompts/` 里的表格都是**可复制整行**的，不需要改写。

## 四个核心原则

1. **先定结构，再想画面。** 短剧是"节奏工业品"，不是画面艺术片。先把 6 段节奏和每段镜头数定死，再谈画得好不好。
2. **描述块原文照抄，禁止同义改写。** 角色一致性崩掉的最主要原因，是每镜都把"银灰色短发"写成"灰发""银发""浅灰头发"。模型不认同义词。
3. **能用图生图就不要文生图。** 首帧确定后，后续镜头一律参考首帧，只改动作和场景。
4. **每镜只表达一件事。** 一镜里塞进"吵架 + 摔门 + 转身 + 落泪"，出来的一定是四不像。

## 常见问题

**Q：这些模板能商用吗？**
内容按 CC BY 4.0 授权，署名后自由商用。你基于模板生成的图片/视频版权归属，取决于你所用的生成平台条款，与本仓库无关。

**Q：为什么不直接给"万能提示词"？**
不存在通用万能提示词。同一个词在不同模型、不同题材下权重完全不同。本仓库给的是**结构 + 可替换槽位**，你填自己的内容。

**Q：`.md` 文件里为什么强调"中英对照"？**
大多数图像/视频模型对英文镜头术语的理解更准（`dolly in` 比"推镜头"稳），但分镜表本身用中文更利于团队协作。所以：**表格中文、提示词英文**。
