# 短剧节奏与分镜结构

> 先读这一篇。一集 60~90 秒的竖屏短剧，节奏是"算出来的"，不是"感觉出来的"。

## 一、为什么节奏必须先定

AI 生成单镜的成本很低，所以新手最容易犯的错是**先出一堆好看的图，再剪在一起**。结果是：

- 前 3 秒在交代背景 → 完播率崩
- 中段画面很美但信息密度低 → 划走
- 结尾没有钩子 → 没有下一集

正确顺序是：**先写节奏表（每段几秒、几镜、发生什么）→ 再写分镜表（每镜画面）→ 再出图**。

## 二、六段式节奏表（60~90 秒 / 竖屏 9:16）

| 段 | 名称 | 时长占比 | 建议镜数 | 单镜时长 | 这一段要干什么 |
|---|---|---|---|---|---|
| 1 | **黄金钩子** | 0~3s（约 4%） | 1~2 | 1~2s | 冲突**前置**。不要说"三年前…"，直接给最刺激的一帧 |
| 2 | **情境交代** | 3~15s（约 15%） | 3~5 | 3~4s | 谁、在哪、什么处境。信息一次给完，不重复 |
| 3 | **冲突升级** | 15~40s（约 30%） | 6~8 | 2~3s | 压迫感递增，反派连续得势，主角被逼到墙角 |
| 4 | **反转点** | 40~55s（约 18%） | 2~3 | 2~3s | 身份/能力/底牌揭示。**全片最贵的一镜** |
| 5 | **爽点释放** | 55~75s（约 25%） | 4~6 | 1.5~2.5s | 打脸、碾压、众目睽睽。快切，不给喘息 |
| 6 | **悬念收尾** | 75~90s（约 8%） | 1~2 | 2~3s | 抛出下一集的诱因。**永远不要在圆满处结束** |

**合计 18~26 镜。** 超过 26 镜通常意味着你把两集的内容塞进了一集。

### 单镜时长的三种用途

| 时长 | 用途 | 例子 |
|---|---|---|
| **1~1.5s** | 冲击、闪回、打脸瞬间 | 巴掌落下、合同撕碎、名牌掉落 |
| **2~3s** | 叙事推进、对话 | 反派说话、主角反应 |
| **4~6s** | 情绪停留、氛围 | 雨中独站、空镜、眼神特写 |

> 经验值：**升级段和爽点段用短镜，情绪段用长镜**。全片平均单镜时长控制在 2.5~3.5s，低于 2s 会晕，高于 5s 会掉。

## 三、钩子的 8 种写法（第 1 段用）

| 类型 | 台词/画面模板 | 适配题材 |
|---|---|---|
| 身份错位 | 她被推倒在地，抬头时露出手腕上的家族徽记 | 战神归来、豪门 |
| 当众羞辱 | "你这种人也配进这个门？" 全桌哄笑 | 都市、职场 |
| 极致反差 | 外卖服下是定制西装，头盔摘下是一张冷脸 | 战神、职场逆袭 |
| 死亡预告 | 医疗报告飘落：仅剩三个月 | 悬疑、虐恋 |
| 婚礼事故 | 交换戒指前，大屏亮起另一段视频 | 甜宠、宅斗 |
| 时间压迫 | 倒计时 00:59，炸弹绑在椅子上 | 悬疑 |
| 悬案现场 | 警方拉起警戒线，主角站在死者身旁 | 悬疑反转 |
| 萌宝认亲 | 五岁小孩拉住陌生男人衣角："爸爸" | 萌宝团宠 |

**写钩子的铁律**：第 1 镜**不带字幕交代背景**，观众看画面就该知道"出事了"。字幕只用来补人名和设定。

## 四、分镜表字段定义

出图、剪辑、对轴全靠这张表。建议用 CSV / JSON 管理，字段固定：

| 字段 | 说明 | 示例 |
|---|---|---|
| `shot` | 镜号，三位数，按时间顺序 | `012` |
| `seg` | 所属段（1~6） | `3` |
| `dur` | 时长（秒） | `2.5` |
| `size` | 景别 | `medium close-up` |
| `angle` | 机位角度 | `low angle` |
| `move` | 运镜 | `slow dolly in` |
| `lens` | 焦段/景深 | `85mm, shallow DOF` |
| `content` | 画面内容（谁在哪做什么，一句话） | 林晚被推倒，合同散落一地 |
| `line` | 台词 / 音效 | "你算什么东西？" / 玻璃碎裂声 |
| `prompt` | 完整出图提示词 | 见下方拼接公式 |
| `look` | 角色造型编号（一致性锚点） | `LOOK-01` |
| `note` | 备注（特效、参考图、禁用项） | 参考帧 011.png |

### 提示词拼接公式

```
[画风固定前缀] + [角色描述块（原文照抄）] + [景别/机位/运镜/焦段] + [光线] + [场景] + [情绪/氛围]
```

例：

```
cinematic film still, anamorphic lens, film grain, 2.39:1 ->
林晚，25 岁女性，鹅蛋脸，丹凤眼，黑长直发，中等身高，米白风衣配黑高领，银色细项链，清冷气质 ->
medium close-up, low angle, slow dolly in, 85mm, shallow depth of field, bokeh ->
hard side light, cool 5600K, rim light ->
现代写字楼大堂，大理石地面，玻璃幕墙反光 ->
压制感，隐忍，眼眶微红但不落泪
```

写成**一段**（逗号连接）交给模型，箭头只是给人看的层级分隔，不要真的输出箭头。

## 五、每集的自检清单

出图前过一遍，任何一条不通过就别开工：

- [ ] 第 1 镜是不是**冲突**，而不是背景介绍？
- [ ] 3 秒内观众能不能判断"谁是坏人 / 主角遇到什么麻烦"？
- [ ] 冲突升级段有没有**至少 3 次**递增的压迫（而不是重复同一种打压）？
- [ ] 反转点之前，观众有没有被误导到一个错误预期？
- [ ] 爽点段有没有一个**可视化的打脸动作**（下跪、跪求、当众道歉、文件甩脸）？
- [ ] 最后一镜是不是**新问题**，而不是"从此幸福生活"？
- [ ] 全片角色造型是否都写了 `LOOK-0x` 编号？
- [ ] 有没有哪一镜塞了两个以上动作？

## 六、时长与镜数的快速换算

| 目标时长 | 建议镜数 | 分配（钩子/交代/升级/反转/爽点/悬念） |
|---|---|---|
| 60s | 18~20 | 1 / 3 / 7 / 2 / 5 / 1 |
| 75s | 21~23 | 2 / 4 / 7 / 3 / 5 / 2 |
| 90s | 24~26 | 2 / 5 / 8 / 3 / 6 / 2 |

起步建议做 **60 秒 / 20 镜**。短剧是"迭代游戏"，先跑通一集再拉长度。
