# 镜头语言对照表（中文 → 英文提示词）

> 英文镜头术语在图像/视频模型里比中文描述稳定得多。分镜表用中文写，提示词里换成右列。

## 一、景别（Shot Size）

| 中文 | 英文提示词 | 画面范围 | 短剧里的用途 |
|---|---|---|---|
| 大远景 | `extreme long shot, ELS` | 人物极小，环境为主 | 开场交代城市/战场 |
| 远景 | `wide shot, WS` | 人物全身 + 大量环境 | 场景建立、孤身感 |
| 全景 | `full shot, FS` | 人物占满画幅高度 | 打斗、走位、服装展示 |
| 中景 | `medium shot, MS` | 腰部以上 | 对话主力镜头 |
| 中近景 | `medium close-up, MCU` | 胸部以上 | **竖屏短剧最常用** |
| 近景 | `close-up, CU` | 头部/肩部 | 情绪、反应 |
| 特写 | `extreme close-up, ECU` | 眼睛/手/嘴 | 决定性细节 |
| 微距 | `macro shot` | 极近，浅景深 | 戒指、纹身、合同签名 |

> 竖屏 9:16 建议主力景别为 **MCU / CU**。WS 在竖屏里两侧信息会被裁掉，谨慎使用。

## 二、机位与角度（Camera Angle）

| 中文 | 英文提示词 | 心理效果 |
|---|---|---|
| 平视 | `eye-level shot` | 中性、平等、对话 |
| 仰拍 | `low angle shot` | 压迫、崇敬、力量感（主角/反派） |
| 俯拍 | `high angle shot` | 弱小、无助、被审视 |
| 过肩 | `over-the-shoulder shot, OTS` | 对话的"对话感" |
| 主观视角 | `POV shot, first-person view` | 代入，观众即角色 |
| 荷兰角 | `dutch angle, tilted camera` | 失衡、不安、悬疑 |
| 鸟瞰 | `bird's-eye view, top-down` | 上帝视角、绝望、布局感 |
| 背影 | `shot from behind, back view` | 隐瞒、离场、决绝 |

**搭配规律（短剧最常用三组）**

- 反派施压 → `low angle` + `wide-angle 24mm`（近大远小，脸更凶）
- 主角被压 → `high angle` + `medium close-up`（显得抬不起头）
- 反转揭示 → 从 `high angle` 切到 `low angle`（一个剪辑完成情绪翻盘）

## 三、运镜（Camera Movement）

| 中文 | 英文提示词 | 常见用途 |
|---|---|---|
| 固定 | `static shot, locked-off camera` | 对话、独白（最稳，新手优先） |
| 推 | `slow dolly in` / `push in` | 聚焦、压迫、揭示 |
| 拉 | `dolly out` / `pull back` | 孤立、结束、环境揭示 |
| 摇 | `pan left / pan right` | 扫视、跟随视线 |
| 移 | `tracking shot, lateral dolly` | 走位、并行叙事 |
| 跟随 | `follow shot, camera follows subject` | 追逐、行走 |
| 环绕 | `orbit shot, camera circles subject` | 高光时刻、产品展示 |
| 升降 | `crane shot, rising / descending` | 场面调度、结尾 |
| 手持 | `handheld camera, slight shake` | 纪实、紧张、冲突 |
| 斯坦尼康 | `steadicam, smooth stabilized movement` | 长镜头流畅跟拍 |
| 甩镜 | `whip pan transition` | 快速转场 |
| 变焦推拉 | `dolly zoom, vertigo effect` | 心理崩塌、震惊 |
| 无人机 | `aerial drone shot, flying over` | 大场面前提必要 |

> **AI 视频的运镜建议**：一次只写**一种**运镜。写"先推再摇再环绕"的结果通常是画面乱扭。类型片里最稳的三选：`slow dolly in`（聚焦）、`static shot`（对话）、`orbit`（展示）。

## 四、焦段与景深（Lens & Depth of Field）

| 中文 | 英文提示词 | 视觉特征 |
|---|---|---|
| 广角 | `wide-angle, 24mm` | 空间夸张、畸变、紧张 |
| 标准 | `35mm` / `50mm` | 接近人眼，纪实 |
| 中长焦 | `85mm` | 人像黄金焦段，脸自然好看 |
| 长焦 | `135mm, telephoto` | 压缩空间、偷窥感 |
| 浅景深 | `shallow depth of field, bokeh, f/1.8` | 主体突出、虚化背景 |
| 深景深 | `deep focus, f/11` | 前后都清晰，群像 |
| 微距 | `macro lens, extreme detail` | 细节材质 |
| 变形宽银幕 | `anamorphic lens, horizontal flares` | 电影感来源 |

**"电影感"配方（最常抄的一条）**：

```
cinematic film still, anamorphic lens, shallow depth of field,
film grain, subtle lens flare, 2.39:1 cinematic framing
```

## 五、构图（Composition）

| 中文 | 英文提示词 | 用途 |
|---|---|---|
| 三分法 | `rule of thirds composition` | 通用，最安全 |
| 中心对称 | `symmetrical composition, centered` | 仪式感、权力、威压 |
| 引导线 | `leading lines` | 视线导向 |
| 前景遮挡 | `framing with foreground elements` | 偷窥、层次 |
| 框架构图 | `framed through doorway / window` | 被困、旁观 |
| 留白 | `negative space, minimalist composition` | 孤独、文艺 |
| 低地平线 | `low horizon line, subject against sky` | 英雄感 |
| 三角构图 | `triangular composition, three subjects` | 群像稳定感 |
| 对角线 | `diagonal composition` | 动感、不安 |

