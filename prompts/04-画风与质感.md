# 画风与质感

> 风格混乱的根源：把"风格"当成形容词随机撒。正确做法是把它做成一整块**固定前缀**，全片照抄。

## 一、固定前缀法

选一个风格块，写在每一镜提示词的**最前面**，一个字不改：

| 风格 | 固定前缀（照抄） |
|---|---|
| 写实电影感 | `cinematic film still, photorealistic, anamorphic lens, film grain, shallow depth of field` |
| 国漫（漫画风） | `Chinese manhua style, cel shading, clean bold line art, vivid colors, comic panel aesthetic` |
| 国漫（水墨风） | `Chinese ink painting style, xuan paper texture, flowing brush strokes, muted ink wash palette` |
| 韩漫（网漫风） | `Korean webtoon style, soft cel shading, pastel palette, clean lineart, glossy highlights` |
| 日系动画 | `anime style, cel shading, vibrant colors, detailed background, studio quality` |
| 3D 动画 | `Pixar-style 3D render, subsurface scattering, soft global illumination, stylized proportions` |
| 港片复古 | `1980s Hong Kong cinema, warm faded film, heavy grain, neon signs, cyan-magenta cast` |
| 赛博朋克 | `cyberpunk, neon noir, high contrast, holographic signage, rainy night, magenta and cyan` |
| 黑白胶片 | `black and white film, high contrast, silver halide grain, dramatic shadows` |
| 唯美插画 | `digital illustration, soft gradient shading, delicate lineart, dreamy atmosphere` |

**一条铁律**：全片**只用一种**主风格前缀。需要区分"回忆 / 现在"时，用**同一风格 + 不同调色**（如都走写实电影感，回忆段加 `desaturated, warm fade, soft focus`），不要换风格本体。

## 二、质感关键词（决定"贵不贵"）

```
film grain           胶片颗粒        → 去数码味
halation             光晕溢出        → 高光处泛红，电影感
subsurface scattering 次表面散射     → 皮肤透亮（3D/写实必备）
micro detail         微观细节        → 布料纹理、毛孔
pores, skin texture  皮肤纹理        → 避免"塑料脸"
fabric weave         织物纹理        → 衣服不糊成色块
wet surface          湿润表面        → 雨戏、汗、泪
dust motes           空气尘埃        → 空间感
```

**反面词（越写越糟）**：`4K`、`8K`、`ultra HD`、`masterpiece`、`best quality`、`award winning`、`超高清`。
这些是被大量低质数据污染的"无效词"，对画面结构没有任何约束作用。删掉它们，换成上表的具体质感词。

## 三、写实电影感（最常用的完整配方）

```
cinematic film still, photorealistic, anamorphic lens, 2.39:1 framing,
film grain, subtle halation, shallow depth of field, natural skin texture,
[景别/机位/运镜/焦段], [主光位 + 光质 + 色温], [场景], [人物描述块], [情绪]
```

## 四、国漫 / 漫剧（竖屏漫剧最常用）

```
Chinese manhua style, cel shading, bold clean line art, vivid saturated colors,
dramatic lighting with hard shadow shapes, dynamic composition,
[景别/机位], [场景], [人物描述块], [情绪]
```

**漫剧区别于动画的关键**：大量使用 **dynamic composition + speed lines（速度线）+ impact frame（冲击帧）**。

```
speed lines, motion blur streaks
impact frame, radial burst background
screen tone dots, halftone shading
```

## 五、风格统一自检

- [ ] 全片是不是同一个风格前缀？有没有混用？
- [ ] "回忆/现在/梦境"的区分是否用**调色**而不是换风格？
- [ ] 提示词里有没有残留 `4K/8K/masterpiece` 之类的无效词？
- [ ] 皮肤是否有 `skin texture / pores`（避免塑料感）？
- [ ] 服装是否有 `fabric texture`（避免糊成色块）？
- [ ] 漫剧是否给了 `line art` + `cel shading` 两个必备项？
