# 角色一致性（最影响成片质量的一篇）

> 现象：第 1 集男主是剑眉星目，第 3 集变成圆脸路人。这不是模型不行，是提示词写法不对。

## 一、根因：同义词改写

模型不认"同义"。以下四种写法，在模型眼里是**四个不同的人**：

```
银灰色短发 / 灰发 / 银色短发 / 浅灰色头发
```

同理还有：`丹凤眼 / 上挑眼 / 凤眼`、`黑色西装 / 深色西装 / 黑西服`。

**规则：角色描述块写一次，之后每一镜原文照抄，一个标点都不改。**

## 二、八槽位角色描述块（模板）

把角色拆成 8 个槽位，填满后**锁死**。所有镜头复用同一段。

```yaml
角色: 林晚
01_年龄性别: 25 岁女性
02_脸型五官: 鹅蛋脸，丹凤眼，鼻梁挺直，唇形饱满，左眉尾有一道浅疤
03_发型发色: 黑色长直发及腰，中分，无刘海
04_体型身高: 偏瘦，身高约 168cm，肩窄
05_服装编号: LOOK-01
06_配饰: 银色细项链，左手腕细银镯
07_气质: 清冷克制，眼神有攻击性
08_禁用项: 不化浓妆、不戴眼镜、不换发色
```

### 服装用编号管理（关键）

不要每镜重写服装，改成编号索引：

| 编号 | 造型描述（原文照抄用） | 出现场景 |
|---|---|---|
| `LOOK-01` | 米白色长风衣，黑色高领针织衫，黑色直筒西裤，黑色乐福鞋 | 第 1~3 集日常 |
| `LOOK-02` | 深灰色定制西装三件套，白色衬衫，酒红色丝巾 | 职场线 |
| `LOOK-03` | 香槟色真丝晚礼服，盘发，珍珠耳坠 | 宴会/打脸场 |
| `LOOK-04` | 白色简易病号服，素颜，长发披散 | 医院戏 |
| `LOOK-05` | 幼年回忆专用：白色连衣裙，双马尾，帆布鞋 | 闪回 |

分镜表里 `look` 字段只写编号，提示词生成时再把整行描述替换进去。

## 三、三视图参考法（首帧必做）

正式出图前，先做**角色定妆包**：

1. 生成 **3 张定妆图**：正面平视、3/4 侧面、背面（同一套 `LOOK`）。
2. 再加 **3 张表情图**：平静、愤怒、含泪（正面）。
3. 从中挑 **1 张质量最好的正面图作为"主参考帧"**，后续所有镜头都以它为参考图做**图生图**。

```
正面定妆 prompt 示例：

character reference sheet, front view, neutral expression, plain grey background,
25-year-old Chinese woman, oval face, phoenix eyes, straight nose, full lips,
black waist-length straight hair, center part, slim build,
cream trench coat over black turtleneck, thin silver necklace, silver bracelet,
cold elegant aura, soft studio lighting, full body, feet visible
```

**生成后立刻做的事**：把这一帧存档命名为 `REF-林晚-FRONT.png`，项目里所有后续镜头都引用它。

## 四、图生图控制参数建议

| 目的 | 参考强度（相似度） | 说明 |
|---|---|---|
| 只改表情 | 0.75 ~ 0.90 | 脸部结构几乎不动 |
| 换动作/姿势 | 0.60 ~ 0.80 | 主流通用区间 |
| 换场景/环境 | 0.50 ~ 0.70 | 保留人物，重绘背景 |
| 换服装（同人不同衣） | 0.55 ~ 0.75 | 需同时换 `LOOK` 描述 |
| 年龄变化（幼年） | 0.40 ~ 0.55 | 必须换 `LOOK`，只保脸型特征 |

> 低于 0.4 基本等于文生图，人脸会重新抽卡；高于 0.9 会出现原图残留（姿势改不动、背景糊）。

## 五、固定 seed 与"反抽卡"

- 平台支持 seed 时，**同一角色的所有镜头用同一 seed**，再靠参考图和描述块微调。
- 平台不支持 seed 时，退而求其次：**同一角色连续生成，不自中途换模型版本**。
- 抽到一张"对味"的图，立刻**反向记录它的完整提示词**（含 seed、尺寸、采样步数）。这张图就是新的基准参考帧。

## 六、多人同框的处理

两人以上同框时一致性最容易崩。做法：

1. **分别定妆**：每个人先各自有定妆包（REF-A / REF-B）。
2. **拼参考图**：把两张定妆图横向拼成一张（如 1024×512 → 横向两人），作为图生图输入。
3. 提示词里**按位置指定**：

```
two-person shot, left: 林晚 (cream trench coat, black long hair, LOOK-01),
right: 顾砚 (dark grey three-piece suit, short black hair, LOOK-20), facing each other
```

> 用 `left: / right:` 显式绑定位置，比写"一男一女站在一起"稳定得多。

## 七、一致性自检清单

- [ ] 每个主要角色都有八槽位描述块，且已锁死不改？
- [ ] 每套服装都有 `LOOK-0x` 编号并被分镜表引用？
- [ ] 每个角色都有一张 `REF-*.png` 主参考帧？
- [ ] 后续镜头是否都走**图生图**而非文生图？
- [ ] 同角色的参考强度是否在 0.5~0.9 之间（没有过高或过低）？
- [ ] 多人同框时是否用了 `left:/right:` 位置绑定？
- [ ] 有没有哪一镜偷偷改写同义词（"灰发"vs"银发"）？

## 八、最容易忽略的一条

**角色一致性不只是脸，还包括"光下的肤色表现"。**

同一个角色，在 `3200K 暖光` 下和 `5600K 冷光` 下会像两个人。所以定妆包的光线条件要写进角色描述块：

```yaml
09_光线基准: 中性柔光 5600K，无强阴影
```

后续镜头若必须换光（例如夜戏冷光），就在提示词里显式声明"同一人物，光线改为 neon noir"——**让"变化"是你主动指定的，而不是模型随机给的**。
