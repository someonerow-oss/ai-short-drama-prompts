# 工作流：图 → 视频 参数与运镜建议

> 已有静态分镜图，要变成 3~8 秒的动态镜头。这一步决定成片"像不像视频"。

## 一、单镜时长怎么给

| 镜头类型 | 建议时长 | 说明 |
|---|---|---|
| 打脸瞬间 / 闪回 | 1.5~2.5s | 越短越有力，长了会泄气 |
| 对话 / 反应 | 2.5~4s | 配合台词节拍 |
| 情绪停留 / 空镜 | 4~6s | 适合运镜（推、拉、环绕） |
| 大场面建立 | 5~8s | 需要更长的运镜时间才不突兀 |

**总原则**：AI 视频**越长越容易崩**（形变、跳帧、多手多脚）。宁可生成 3 秒再剪辑，也不要硬要 10 秒。

## 二、运镜与图像类型的匹配表

| 画面类型 | 推荐运镜 | 避免 |
|---|---|---|
| 人物特写（面部） | `slow dolly in`、`static with subtle breathing` | `whip pan`、`orbit`（必崩脸） |
| 中景对话 | `static`、`slight handheld` | `crane`、`dolly zoom` |
| 全身/走位 | `tracking shot`、`follow shot` | `orbit`（转身时易形变） |
| 物体特写 | `slow push in`、`orbit` | 快速运动 |
| 环境空镜 | `crane rising`、`aerial drone`、`slow pan` | 无 |
| 打斗/冲突 | `handheld with shake`、`whip pan` | 长镜头（动作不连贯） |
| 展示类（商品） | `orbit`、`dolly in`、`turntable` | 手持抖动 |

> **一条铁律**：**一次只写一种运镜**。写"先推再摇再环绕"，产出大概率是画面扭曲。

## 三、提示词写法（图像 → 视频）

把静态图的 prompt 改成"运动描述"，而非重新描述画面：

```
❌ 错误做法（重新描述画面，等于重画）：
cinematic still of a woman in cream coat standing in rain...

✅ 正确做法（只描述运动）：
slow dolly in, camera pushes toward her face,
rain continues falling, hair gently swaying,
subtle breathing motion, slight head turn to the left,
cinematic, photorealistic, consistent face
```

**图像 → 视频的通用模板**：

```
[运镜] + [主体微动作] + [环境持续运动] + [镜头物理感]
```

其中"环境持续运动"是让画面"活起来"的关键：`rain continues falling`、`smoke drifting slowly`、`hair and fabric gently swaying`、`neon signs flickering`、`dust particles floating`。

## 四、首尾帧衔接（多镜连贯）

同一场景的连续镜头，用**上一镜的末帧作为下一镜的首帧**，可显著减少跳变：

```
镜 011 末帧 → 导出 PNG → 作为镜 012 的 image-to-video 输入
```

**衔接三原则**：

1. **同场景不换光**。同一场戏内色温、主光方向必须一致。
2. **动作接动作**，不要状态接状态。上一镜"举起手"，下一镜从"手已在空中"开始。
3. **机位不能跳轴**。人物 A 在画面左、B 在右，切换机位后不能左右互换（越轴）。

## 五、参考强度 / 相似度参数

| 平台参数名 | 建议值 | 说明 |
|---|---|---|
| 图生视频首帧权重 | 0.85~1.0 | 越高越忠于原图，但动作幅度越小 |
| 动作幅度 / motion | 3~5（中低档） | 高档易崩，尤其是人脸 |
| 一致性 / reference | 有则给足 | 有角色一致性控制就用满 |
| 随机度 / 种子 | 固定 | 同场景连续镜头固定 seed，减少跳变 |

## 六、常见崩坏与对症

| 崩坏现象 | 主要原因 | 处理 |
|---|---|---|
| 脸变形 / 换人 | 动作幅度过大、运镜过猛 | 降 motion、改 `slow dolly in`、缩短时长 |
| 手部畸形 | 手部进入画面且运动 | 构图避开手，或用前景遮挡 |
| 背景融化 | 运镜过快或场景过复杂 | 简化背景、降低运动幅度 |
| 闪烁跳帧 | 生成时长过长 | 拆成 2~3 秒多段生成后剪辑 |
| 衣服颜色突变 | 光线描述缺失或不稳定 | 补全色温 + 主光方向，同场戏保持一致 |
| 人物"漂移"出画 | 运镜与主体运动方向冲突 | 运镜方向与主体运动方向保持一致 |

## 七、剪辑收尾清单

- [ ] 每镜是否已按"六段节奏"标注段号与时长？
- [ ] 升级段与爽点段是否用短镜 + 快切？
- [ ] 反转点是否有一个明显的**镜别或角度变化**（如 high angle → low angle）？
- [ ] 同场景内光线/色温是否统一？
- [ ] 是否有多余的 0.3~0.5 秒静帧可裁掉？（**每镜裁掉 0.3s，全片能快 6 秒**）
- [ ] 最后一镜是否留下了新问题？
- [ ] 字幕是否只用于补人名/设定，而非交代剧情？
